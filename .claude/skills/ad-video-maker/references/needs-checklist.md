# 1단계 — 니즈 일괄 수집 (질문 ①)

이 단계는 유저에게 질문할 수 있는 **첫 번째이자 가장 큰 관문**이다.
여기서 빠뜨린 정보는 이후 절대 물어볼 수 없으므로(4단계 이후 질문 금지 원칙),
아래 항목을 빠짐없이 수집한다.

## 수집 항목 전체 목록

| 분류 | 항목 | 비고 |
|------|------|------|
| 광고 기본 | 광고 대상 (제품/서비스/브랜드명) | 유저 최초 요청에서 추출 시도 |
| 광고 기본 | 핵심 메시지 (1문장) | |
| 광고 기본 | CTA (구매/방문/다운로드/문의 등) | |
| **타깃 시장** | **지역** (한국/북미/유럽/일본/동남아/중동/남미/글로벌) | 벤치마킹 검색 언어 결정 |
| **타깃 시장** | **인종·문화권** (등장인물·배경에 반영) | 힉스필드 프롬프트에 직결 |
| **타깃 시장** | **언어** (자막·내레이션) | 지역과 다를 수 있음 (예: 북미 시장 + 한국어 자막) |
| 포맷 | 비율 (16:9 / 9:16 / 1:1) | Remotion Composition 선택 |
| 포맷 | 길이 (15초 / 30초 / 60초) | 씬 수 결정: 대략 씬당 4~6초 + 아웃트로 2~3초 |
| 포맷 | 게재 플랫폼 (YouTube / Shorts / Reels / TikTok / 인스타 피드) | |
| 크리에이티브 | 톤앤매너 (감성적/역동적/신뢰감/유머/프리미엄) | |
| 크리에이티브 | 선호·기피 스타일 (선택 입력) | |
| **오디오** | **음성 구성** (내레이션+BGM / 등장인물 대사+BGM / BGM만+자막 / 무음+자막) | 내레이션=화면 밖 목소리, 대사=영상 속 인물이 직접 발화(립싱크). **대사 선택 시 음성 지원 비디오 모델이 필요**하므로 4단계 모델 선정에 직결 |
| 오디오 | 보이스 선호 (성별·톤, 선택 입력) | 내레이션·대사 있을 때만. 미응답 시 톤앤매너로 자동 선택 |
| **입력 소재** | **제품 이미지 보유 여부 + 파일 경로** | 있으면 힉스필드 참조 입력으로 사용 (제품 외형 보존) |
| **입력 소재** | 로고 파일 (선택) | 아웃트로에 표시 |
| 입력 소재 | 보유 음원 (BGM·성우 녹음, 선택) | 있으면 생성 대신 사용. `uploads/` 폴더도 확인 |
| 리소스 | **크레딧 사용 상한** (예: 100 / 300 / 500 / 제한 없음) | 3~4단계 자율 운영의 예산 계약 |

## 진행 방법

1. **유저의 최초 요청 문장을 먼저 분석**해 이미 답이 있는 항목(제품명, 비율 등)은 질문에서 제외한다.
   이유: 이미 말한 것을 다시 물으면 신뢰를 잃는다.
2. 광고 대상·핵심 메시지가 최초 요청에 없으면 자유 서술로 먼저 받는다
   (선택지로 만들 수 없는 항목이므로 일반 텍스트 질문 또는 AskUserQuestion의 Other 활용).
3. 나머지 항목은 AskUserQuestion으로 수집한다. 한 호출에 최대 4개 질문이므로 **연속 2회 호출**로 나눈다.
   두 호출 모두 1단계 안에서 이뤄지므로 "질문 관문 1회"로 간주한다.

### 권장 질문 구성

**호출 1 — 타깃 시장 (조사 방향 결정)**
- 타깃 지역 (한국 / 북미 / 유럽 / 일본 — Other로 기타 지역)
- 타깃 인종·문화권 (지역 답변과 연동된 선택지 구성, multiSelect 허용)
- 자막·내레이션 언어
- 톤앤매너

**호출 2 — 포맷·오디오·예산**
- 비율 (16:9 유튜브 / 9:16 쇼츠·릴스 / 1:1 피드) + 게재 플랫폼은 비율 선택지 설명에 병기
- 길이 (15초 / 30초 / 60초)
- 음성 구성 (내레이션+BGM / 등장인물 대사+BGM / BGM만+자막 / 무음+자막 — 보이스 성별·톤 선호는 Other/notes로.
  선택지 설명에 "내레이션 = 화면 밖 목소리 / 대사 = 영상 속 인물이 직접 말함"을 병기해 혼동을 막는다)
- 크레딧 사용 상한 (~100 절약형 / ~300 표준 / ~500 고품질 / 제한 없음)

**제품 이미지·로고 수집 (호출 2 직후, 여전히 1단계 안)**
- "제품 이미지 있음 (경로 입력) / 없음 (AI 생성으로 진행)" 을 질문에 포함하거나,
  유저가 이미 경로·파일을 언급했으면 그것을 사용한다.
- 경로를 받으면 즉시 검증한다: 파일 존재 확인 → 이미지 확장자(png/jpg/jpeg/webp) 확인 →
  `ad-videos/<slug>/assets/input/` 에 복사. 로고도 동일하게 처리.
- **`uploads/` 폴더를 이 시점에 확인**한다: 이미지·로고 외에 음원(mp3/wav/m4a)이 있으면
  용도(BGM/내레이션)를 이 관문에서 확인받고 `assets/input/` 에 복사한다 (생성 대신 사용).
- 파일이 없거나 손상된 경로면 **이 시점에** 재확인한다 (1단계 안에서는 질문 가능).
  4단계 진입 후에는 이미지 문제를 물어볼 수 없으므로 검증을 반드시 여기서 끝낸다.

## 산출물: brief.md

수집 결과를 아래 형식으로 `ad-videos/<slug>/brief.md` 에 저장한다.

```markdown
# 광고 브리프 — <프로젝트명>
- 작성일: <YYYY-MM-DD>
## 광고 기본
- 대상: / 핵심 메시지: / CTA:
## 타깃 시장
- 지역: / 인종·문화권: / 언어:
## 포맷
- 비율: / 길이: / 플랫폼:
## 크리에이티브
- 톤앤매너: / 선호·기피:
## 오디오
- 음성 구성: (내레이션+BGM / 등장인물 대사+BGM / BGM만 / 무음) / 보이스 선호: (성별·톤 또는 "자동")
## 입력 소재
- 제품 이미지: (경로 또는 "없음 — AI 생성") / 로고: (경로 또는 없음) / 보유 음원: (경로·용도 또는 없음)
## 리소스
- 크레딧 상한: (예비비 10% = X 크레딧)
```

brief.md 저장 후 즉시 2단계로 진행한다 (추가 확인 질문 금지).
