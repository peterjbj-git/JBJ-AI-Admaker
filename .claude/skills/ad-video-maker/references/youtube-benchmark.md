# 2단계 — 지역 맞춤 유튜브 벤치마킹 (질문 ②)

목적: 타깃 시장에서 실제로 통하는 광고 스타일을 조사해, 스토리보드의 크리에이티브
기준을 세운다. 조사는 반드시 **brief.md의 타깃 지역·언어 기준**으로 현지화한다.

## 검색 전략

### 지역별 검색 언어·키워드

| 타깃 지역 | 검색 언어 | 키워드 예시 |
|-----------|-----------|-------------|
| 한국 | 한국어 | `<업종> 광고 유튜브 2026`, `<제품군> 바이럴 광고` |
| 북미 | 영어 | `best <category> commercial 2026`, `<category> ad viral` |
| 일본 | 일본어 | `<業種> CM 2026`, `話題のCM <カテゴリ>` |
| 유럽 | 영어+현지어 | `<category> advert 2026`, 독일·프랑스 타깃이면 현지어 병행 |
| 동남아 | 영어 우선 | `<category> TVC 2026 Vietnam/Thailand/Indonesia` |
| 중동 | 영어+아랍어 | `<category> commercial UAE/Saudi 2026` |
| 글로벌 | 영어 | 칸 라이언즈/YouTube Works 수상작 위주 |

### 검색 실행 (WebSearch 우선, 브라우저 폴백)

1. WebSearch로 `site:youtube.com <키워드>` 형태 검색 + 일반 검색("<지역> 광고 트렌드 2026") 병행.
2. WebFetch로 후보 영상 페이지·기사 내용을 확인해 스타일 정보를 보강한다.
3. 썸네일·조회수·댓글 반응까지 필요하면 Claude in Chrome 브라우저 자동화로 폴백한다
   (유튜브 검색 결과 페이지를 직접 조회).
4. 플랫폼 관행 반영: 쇼츠/릴스/틱톡 타깃이면 세로형·3초 훅·빠른 컷 위주 사례를,
   유튜브 인스트림이면 5초 스킵 전 훅이 있는 사례를 우선 수집한다.

## 분석 프레임 — 영상당 아래 5요소를 기록

| 요소 | 관찰 내용 |
|------|-----------|
| 오프닝 훅 | 첫 3초에 무엇으로 시선을 잡는가 (질문/충격 비주얼/사운드) |
| 편집 템포 | 컷 길이, 전환 방식 (빠른 컷 vs 롱테이크) |
| 컬러·룩 | 색감, 조명, 실사/모션그래픽/애니메이션 |
| 자막·타이포 | 자막 스타일, 텍스트 오버레이 사용 정도 |
| CTA 방식 | 엔딩 처리, 로고 노출, 행동 유도 문구 |

## 방향 후보 제시 및 선택 (질문 ②)

1. 조사한 3~5편을 표(제목·채널·URL·5요소 분석)로 정리해 유저에게 보여준다.
2. 분석 결과를 조합해 **방향 후보 2~4개**를 만든다. 각 후보는
   "훅 전략 + 템포 + 룩 + 자막 스타일"의 완결된 패키지로 기술한다.
   예: "A안 — 3초 제품 클로즈업 훅 + 빠른 컷 + 고채도 팝 컬러 + 대형 키네틱 자막 (참고: 영상1·3)"
3. AskUserQuestion으로 선택받는다. multiSelect를 켜서 여러 안의 요소를 조합할 수 있게 하고,
   가장 brief에 부합한다고 판단되는 안을 첫 번째에 두고 "(Recommended)"를 붙인다.
4. 선택 결과 + 근거를 `benchmark.md` 에 기록하고 3단계로 진행한다.

## 산출물: benchmark.md

```markdown
# 벤치마킹 조사 — <프로젝트명>
## 조사 조건
- 타깃 지역/언어: / 검색 키워드:
## 참고 영상
| # | 제목 | 채널 | URL | 훅 | 템포 | 컬러 | 자막 | CTA |
## 방향 후보와 유저 선택
- 후보 A/B/C 요약, 유저 선택: <선택안>, 선정 근거:
```

주의: 검색 결과가 빈약하면 키워드를 바꿔 2~3회 더 시도하되, 조사 단계에서
30분 이상 소모하지 않는다. 충분한 사례 3편이면 다음 단계로 넘어간다.
