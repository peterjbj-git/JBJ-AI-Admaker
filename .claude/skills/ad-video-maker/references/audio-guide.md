# 오디오 가이드 — BGM · 내레이션 · SFX (4단계에서 사용)

광고의 오디오는 BGM(분위기) + 내레이션(메시지) + SFX(강조) 세 층으로 구성한다.
스토리보드 확정 시점에 오디오 계획(트랙 구성·대본·예상 크레딧)도 함께 확정되어 있어야 하며,
이 문서는 그 계획을 실제 에셋으로 만드는 절차를 다룬다. 무중단 구간이므로 질문 금지.

## 0. 우선순위 (크레딧 부족 시 포기 순서)

**음성(내레이션 또는 대사) > BGM > SFX** — 메시지 전달이 분위기보다 우선한다.

- 크레딧이 부족하면 SFX부터 생략하고, 그다음 BGM을 생략한다(무음 + 자막으로 성립 가능).
- 음성 없는 광고(자막 온리)로 기획된 경우에는 BGM이 최우선이 된다.
- **등장인물 대사**는 4단계 비디오 생성에 포함되어 만들어지므로 별도 오디오 크레딧이 들지 않는다.
  brief의 음성 구성이 '대사'면 내레이션 트랙은 만들지 않는다 (두 음성이 겹치면 광고가 산만해진다).
- 유저가 `uploads/` 또는 니즈 수집 때 오디오 파일을 제공했다면 **생성하지 않고 그것을 사용**한다
  (제공 파일은 `assets/input/` 에 복사, 저작권 확인 책임은 유저에게 있음을 report.md에 한 줄 명시).

## 1. BGM 확보

### 생성 모델이 없을 때 (필수 확인)

힉스필드 `generate_audio` 는 음성(TTS) 전용이며, 음악 모델(sonilo_music)은 게임 파이프라인
전용이라 광고 BGM에 쓸 수 없다 (2026-07 기준 — 4단계에서 `models_explore(type:'audio')` 로 재확인).
음악 생성이 불가하면 **로열티프리 라이브러리에서 다운로드**한다:
- 예: incompetech.com (Kevin MacLeod, CC BY 4.0 — 직접 mp3 URL 다운로드 가능)
- 톤앤매너 매핑 표(아래)로 트랙을 고르고, **트랙명·작곡가·라이선스를 report.md에 기록**한다
  (CC BY는 영상 게시 시 출처 표기 의무가 있음을 유저 보고에 명시).

### 프롬프트 공식 (음악 생성 모델이 있는 경우)

```
<장르> + <무드 키워드 2~3개> + <템포(BPM 또는 slow/mid/up-tempo)> + <주요 악기> + <에너지 곡선> + instrumental, no vocals
예: "Upbeat corporate pop, bright and optimistic, 120 BPM, clean electric guitar and claps,
     builds energy toward the end, instrumental, no vocals"
```

- **내레이션이 있으면 반드시 `instrumental, no vocals`** — 보컬과 내레이션이 겹치면 알아들을 수 없다.
- **에너지 곡선을 명시**한다: 훅(도입 2~3초) 임팩트 → 본문 유지 → 아웃트로 고조(builds up) 또는 여운(fades gently).
- **길이**: 총 영상 길이 이상으로 생성한다. 짧으면 Remotion이 루프시키지만 루프 지점이 티 날 수 있어
  전체 길이 이상 1트랙이 안전하다.
- benchmark.md에서 선택된 방향의 음악 스타일(장르·템포)을 그대로 반영한다.

### 톤앤매너 → 장르 매핑 (기본값, 벤치마킹이 우선)

| 광고 톤 | 장르·템포 가이드 |
|---------|-----------------|
| 활기찬 · 젊은 (쇼츠/릴스) | Upbeat pop, funk, 115~128 BPM, 첫 1초부터 임팩트 |
| 신뢰 · 프리미엄 (기업/금융) | Corporate ambient, minimal piano & strings, 80~100 BPM |
| 감성 · 스토리텔링 | Cinematic acoustic, warm piano, 70~90 BPM, 후반 고조 |
| 테크 · 혁신 | Electronic, synth-driven, 100~120 BPM, 미니멀 |
| 식품 · 라이프스타일 | Acoustic folk-pop, 밝은 어쿠스틱 기타, 95~110 BPM |

## 2. 내레이션 생성

### 대본 규칙

- 언어는 brief의 **타깃 언어**를 따른다 (자막 언어와 일치).
- 발화 속도 기준으로 대본 길이를 맞춘다:
  - 한국어: 초당 4~5음절 (30초 영상 → 내레이션 총 20~25초 → 약 90~110음절)
  - 영어: 초당 2.3~2.6단어 (30초 → 약 50~60단어)
- 씬 자막과 내레이션은 **같은 메시지의 변주**여야 한다 (자막을 그대로 읽지 말 것 — 중복감).
- 앞뒤 0.5~1초 여백을 두고, 아웃트로 CTA는 내레이션으로도 반복한다 (마지막 문장 = CTA).
- 확정 대본은 storyboard.md의 씬 표에 씬별로 기록한다.

### 보이스 선택

0. **언어 힌트가 최우선이다.** 비영어 내레이션은 language 파라미터를 지원하는 모델을
   쓴다 (예: `qwen_audio_tts` — `language: "ko"` + `instruction` 으로 성우 톤 지시).
   언어 힌트 없이 영어권 프리셋(seed_audio 기본)으로 생성하면 **로봇·외국인 억양**이 되어
   광고를 통째로 망친다. 생성 후 길이만이 아니라 발음 자연성도 반드시 점검 대상으로 취급한다.
1. `list_voices` 로 사용 가능한 보이스를 조회한다.
2. 선택 기준: **타깃 언어 네이티브 → 타깃 시장의 성별·연령 선호 → 톤앤매너 부합** 순.
   (예: 프리미엄 → 낮고 차분한 톤 / 쇼츠 → 밝고 빠른 톤)
3. 적합한 보이스가 없으면 `generate_audio` 의 TTS/내레이션 기능에 언어·성별·톤을 프롬프트로 명시한다.
4. 생성 후 길이를 확인한다 — 목표 구간보다 ±10% 이상 어긋나면 대본을 줄이거나 늘려 1회 재생성한다
   (재생성 상한은 씬 규칙과 동일하게 2회).

## 3. 등장인물 대사 (영상 속 발화) — brief에서 '대사'를 선택한 경우

대사는 `generate_audio` 가 아니라 **4단계 비디오 생성 시 클립에 직접 포함**된다.
이 결정은 1단계 니즈 수집(음성 구성 질문)에서 이미 내려져 있어야 하며, 4단계에서 임의로 바꾸지 않는다.

- **모델 선정**: `models_explore` 에서 음성(speech/audio) 출력을 지원하는 비디오 모델만 후보로 한다.
  대사 지원 모델이 없으면 — 자율 판단으로 내레이션 방식으로 전환하고 report.md에 기록한다.
- **대본**: 씬당 1~2문장, 씬 길이 기준 발화 가능한 분량(한국어 초당 4~5음절)으로 스토리보드에
  씬별 대사문을 확정해 둔다. 언어는 brief의 타깃 언어.
- **프롬프트 작성**: 대사문을 큰따옴표로 정확히 지정하고 발화 언어·화자(성별·연령·톤)를 명시한다.
  예: `A Korean woman in her 30s says warmly in Korean: "이제 아침이 달라져요", lip-synced`
- **재생성 판단 기준**(씬 규칙과 동일, 최대 2회): 립싱크 붕괴, 대사 누락·왜곡, 언어 오류.
  2회 실패 시 해당 씬은 대사 없는 버전 + 자막으로 대체한다.
- **믹싱**: 대사 오디오는 클립 원음으로 Remotion에 그대로 들어간다(별도 파일 없음).
  BGM은 0.15~0.25로 낮추고, 대사 없는 씬(제품 클로즈업 등)은 scenes.json에서
  `muted: true` 로 클립 원음(환경음)을 제거해 대사 씬과의 오디오 단차를 줄인다.

## 4. SFX (효과음) — 선택 사항

- 씬당 **0~1개**, 전체 영상에 2~4개면 충분하다. 과용하면 싸구려 느낌이 난다.
- 용도 예: 제품 클로즈업 임팩트(whoosh/hit), 로고 등장(shimmer), 전환 강조(swish).
- `generate_audio` 프롬프트 예: "short whoosh transition sound effect, 0.5 seconds, clean, no music"
- 파일명: `sfx-<씬번호>.mp3`. scenes.json의 해당 씬에 `sfx` 필드로 지정하면 씬 시작에 맞춰 재생된다.
- 크레딧 여유가 없으면 가장 먼저 생략한다 (0절 우선순위).

## 4.5 클립 내장 오디오 주의 (필수)

비디오 생성 모델의 `generate_audio: true` 는 앰비언스만이 아니라 **클립마다 다른 배경음악**을
넣는 경우가 많다 (Seedance 확인됨). 전역 BGM이 있는 구성에서 클립 원음을 살려두면
컷마다 다른 내장 음악이 재생되다 컷 경계에서 뚝 끊겨 "BGM이 계속 바뀌는" 결함이 된다.
- **BGM 트랙이 있는 구성**: 렌더 시 전 컷 `muted: true` 가 기본. 특정 컷의 효과음(스플래시 등)이
  꼭 필요하면 그 컷만 videoVolume을 낮게 열되, 내장 음악이 없는지 확인 후 결정한다.
- **BGM 없이 클립 원음을 쓰는 구성**만 videoVolume을 연다.
- 4단계에서 BGM-온리 구성이 확정되어 있으면 생성 시 `generate_audio: false` 로 요청해
  내장 음악 자체를 만들지 않는 것이 가장 깔끔하다.

## 5. 믹싱 기준값 (scenes.json `audio` 설정)

| 구성 | bgmVolume | narrationVolume | sfxVolume | 클립 원음 |
|------|-----------|-----------------|-----------|-----------|
| BGM + 내레이션 | 0.20~0.35 | 1.0 | 0.6~0.8 | muted 권장 |
| BGM + 등장인물 대사 | 0.15~0.25 | — (내레이션 없음) | 0.6~0.8 | 대사 씬 1.0, 무대사 씬 muted |
| BGM만 (자막 온리) | 0.5~0.7 | — | 0.7~0.9 | muted 권장 |
| 내레이션만 | — | 1.0 | 0.6~0.8 | muted 권장 |

- **페이드 기본값**: `bgmFadeInSeconds: 0.5`, `bgmFadeOutSeconds: 1.5` — 끝이 뚝 끊기는 것을 방지한다.
  감성 톤이면 페이드아웃을 2~3초로 늘린다.
- **내레이션 타이밍**: 기본은 0초 시작. 첫 씬을 비주얼 훅으로 쓰는 경우
  `narrationStartSeconds` 로 1~2초 늦춘다.
- 렌더 후 검증: 최종 mp4를 기준으로 ① 내레이션이 BGM에 묻히지 않는지(묻히면 bgmVolume −0.1 후 재렌더),
  ② 영상 끝에서 오디오가 자연스럽게 끝나는지 확인한다.

## 6. 산출물·파일명 규칙

```
assets/bgm.mp3            # BGM 1트랙 (전체 길이 이상)
assets/narration.mp3      # 내레이션 풀트랙 (씬별 분할 생성 시 narration-<씬번호>.mp3 후 결합)
assets/sfx-<씬번호>.mp3   # 효과음 (선택)
```

오디오 관련 자율 판단(트랙 생략, 볼륨 조정, 보이스 교체, 재생성)은 모두 report.md
"자율 판단 내역"에 사유와 함께 기록한다.
