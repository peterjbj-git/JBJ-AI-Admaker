# ad-video-maker 사용 가이드

힉스필드(Higgsfield) MCP + Remotion CLI로 완성형 광고 영상(mp4)을 제작하는
Claude Code 스킬입니다. 유튜브 벤치마킹으로 방향을 잡고, AI로 에셋을 생성한 뒤,
자막·로고·BGM까지 합성한 최종 영상을 출력합니다.

---

## 1. 설치 방법

### 사전 요구사항

| 항목 | 확인 방법 | 비고 |
|------|-----------|------|
| Node.js 18+ | `node --version` | Remotion 실행에 필요 |
| Remotion CLI | `npm i -g @remotion/cli` | 전역 설치 권장 |
| 힉스필드 MCP | Claude Code에서 claude.ai 커넥터 연결 | `balance` 도구 호출로 확인 |
| 힉스필드 크레딧 | 유료 크레딧 잔액 | 영상 1편에 대략 100~500 소모 |

### 설치 절차

1. 이 폴더(`ad-video-maker/`)를 통째로 프로젝트의 `.claude/skills/` 아래에 넣습니다.
   - 특정 프로젝트용: `<프로젝트>/.claude/skills/ad-video-maker/`
   - 모든 프로젝트 공용: `C:/Users/<계정>/.claude/skills/ad-video-maker/`
2. Remotion 템플릿 의존성을 설치합니다 (1회만):
   ```powershell
   cd .claude/skills/ad-video-maker/templates/remotion-ad
   npm install
   ```
3. Claude Code를 재시작하면 스킬이 자동 등록됩니다.

첫 렌더링 시 Chrome Headless Shell(약 113MB)이 자동 다운로드됩니다 — 정상 동작입니다.

## 2. 사용 방법

Claude Code에서 아래처럼 요청하면 스킬이 자동으로 트리거됩니다.

```
"우리 회사 텀블러 광고 영상 만들어줘"
"신제품 홍보용 쇼츠 영상 제작해줘. 제품 사진은 C:\...\product.png"
```

### 진행 흐름 — 질문은 딱 3번

| 순서 | 단계 | 유저가 할 일 |
|------|------|--------------|
| ① | 니즈 수집 | 광고 대상·타깃 지역/인종/언어·비율·길이·톤앤매너·크레딧 상한·제품 이미지 경로를 한 번에 답변 |
| — | 유튜브 벤치마킹 | (자동) 타깃 지역 언어로 트렌드 광고 조사 |
| ② | 방향 선택 | 제시된 벤치마킹 방향 후보 중 선택 |
| ③ | 스토리보드 확정 | 씬 구성·예상 크레딧 검토 후 승인 또는 수정 요청 |
| — | 에셋 생성 → 렌더링 | (자동·무중단) 완성까지 어떤 질문도 없음 |

**핵심 규칙**: 3번째 질문(스토리보드 확정) 이후에는 자리를 비우셔도 됩니다.
생성 실패·크레딧 부족 등 돌발 상황은 스킬이 알아서 처리하고 최종 보고서에 기록합니다.

### 제품 이미지 활용

- 실제 제품 사진이 있으면 첫 질문 때 파일 경로를 알려주세요.
  힉스필드가 그 이미지를 참조해 **실물 외형을 보존한** 영상을 생성합니다.
- 없으면 AI가 프롬프트 기반으로 제품 비주얼을 생성합니다.
- 로고 파일을 주시면 영상 마지막(아웃트로)에 삽입됩니다.

## 3. 산출물

프로젝트마다 `ad-videos/<프로젝트명>/` 폴더에 저장됩니다.

```
ad-videos/<프로젝트명>/
├── brief.md        # 니즈 정리
├── benchmark.md    # 벤치마킹 조사 결과와 선정 근거
├── storyboard.md   # 확정 스토리보드
├── assets/         # AI 생성 에셋 (+input/ 에 제공한 원본)
├── final/          # ★ 최종 mp4
└── report.md       # 제작 보고서 (크레딧 정산 포함)
```

## 4. 폴더 구조 (이 스킬 패키지)

```
ad-video-maker/
├── SKILL.md                    # 스킬 메인 지침 (Claude가 읽는 워크플로우)
├── GUIDE.md                    # 이 문서
├── references/                 # 단계별 상세 지침
│   ├── needs-checklist.md      #   1단계: 질문 설계
│   ├── youtube-benchmark.md    #   2단계: 지역별 벤치마킹 전략
│   ├── higgsfield-prompting.md #   4단계: 생성 모델·프롬프트 가이드
│   └── remotion-pipeline.md    #   5단계: 합성·렌더링 절차
├── templates/remotion-ad/      # Remotion 렌더링 엔진 (scenes.json만 쓰면 조립됨)
└── scripts/download-assets.ps1 # 에셋 다운로드 스크립트 (재시도 내장)
```

## 5. 자주 묻는 질문

**Q. 크레딧은 얼마나 드나요?**
A. 씬 수·모델·재생성 횟수에 따라 다르며, 30초 영상 기준 대략 100~500 크레딧입니다.
첫 질문에서 상한을 정하면 그 안에서만 사용합니다 (예비비 10% 자동 확보).

**Q. 렌더링이 안 돼요.**
A. ① 템플릿에서 `npm install` 을 했는지 ② `node --version` 이 18 이상인지 확인하세요.
그 외 오류는 `references/remotion-pipeline.md` 의 트러블슈팅 표를 참고하세요.

**Q. 세로(쇼츠)와 가로(유튜브) 둘 다 필요해요.**
A. 첫 질문에서 두 비율을 모두 선택하면 같은 에셋으로 두 버전을 렌더링합니다
(힉스필드 생성은 주 비율 기준이므로 보조 비율은 구도가 잘릴 수 있습니다).

**Q. 완성 후 화질을 더 올리고 싶어요.**
A. 완성 보고 후 "업스케일해줘"라고 요청하면 힉스필드 `upscale_video`(2K/4K)를 실행합니다.
"바이럴 가능성 분석해줘"로 성과 예측(`virality_predictor`)도 가능합니다.
